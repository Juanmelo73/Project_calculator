# Calculadora sencilla

Calculadora web basica construida unicamente con HTML, CSS y JavaScript.

## Estructura

```text
Project_calculator/
|-- index.html
|-- css/
|   `-- style.css
|-- js/
|   `-- script.js
|-- .gitignore
`-- README.md
```

## Como ejecutarla

Abre `index.html` directamente en un navegador. Tambien puedes usar la extension Live Server de VS Code.

## Funcionalidades

- Suma, resta, multiplicacion y division.
- Numeros enteros y decimales.
- Limpieza de la expresion con el boton `C`.
- Validacion de operaciones y control de division entre cero.
